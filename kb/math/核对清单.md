## 一、课标条目（第四学段 数与代数）

- [ ] **S-NUM-1**（有理数）理解有理数的意义，能用数轴上的点表示有理数，能比较有理数的大小。
- [ ] **S-NUM-2**（有理数）借助数轴理解相反数和绝对值的意义，掌握求有理数的相反数与绝对值的方法，知道|a|的含义（这里a表示有理数）。
- [ ] **S-NUM-3**（有理数）理解乘方的意义，掌握有理数的加、减、乘、除、乘方及简单的混合运算（以三步以内为主）。
- [ ] **S-NUM-4**（有理数）理解有理数的运算律，能运用运算律简化运算。
- [ ] **S-NUM-5**（有理数）能运用有理数的运算解决简单的问题。
- [ ] **S-ALG-1**（代数式）借助现实情境了解代数式，进一步理解用字母表示数的意义。
- [ ] **S-ALG-2**（代数式）能分析具体问题中的简单数量关系，并用代数式表示。
- [ ] **S-ALG-3**（代数式）会求代数式的值；能根据特定的问题查阅资料，找到所需要的公式，并会代入具体的值进行计算。
- [ ] **S-POL-1**（整式与分式）理解整式的概念，掌握合并同类项和去括号的运算法则，能进行简单的整式加法和减法运算；能进行简单的整式乘法运算（其中多项式相乘仅指一次式之间以及一次式与二次式相乘）。  
  说明：整式乘法部分在八年级上册教学，七年级上册只涉及整式的加减
- [ ] **S-EQ-1**（方程与不等式）能根据现实情境理解方程的意义，能针对具体问题列出方程；理解方程解的意义，经历估计方程解的过程。
- [ ] **S-EQ-2**（方程与不等式）掌握等式的基本性质。
- [ ] **S-EQ-3**（方程与不等式）能解一元一次方程、可化为一元一次方程的分式方程。  
  说明：分式方程在八年级上册教学，七年级上册只涉及一元一次方程
- [ ] **S-EQ-4**（方程与不等式）掌握代入消元法和加减消元法，能解二元一次方程组。  
  说明：七年级下册教学
- [ ] **S-EQ-5**（方程与不等式）能根据具体问题的实际意义，检验方程的解是否合理。
- [ ] **S-INEQ-1**（方程与不等式）结合具体问题，了解不等式的意义，探索不等式的基本性质；能解数字系数的一元一次不等式，并能在数轴上表示出解集。  
  说明：七年级下册教学

## 二、知识点卡片


### 第一章 有理数

- [ ] **M7A-01-01 正数和负数**：用正数和负数表示具有相反意义的量；0 既不是正数也不是负数。
- [ ] **M7A-01-02 有理数的概念与数轴**：有理数的分类；数轴三要素；用数轴上的点表示有理数。  
  课标：S-NUM-1
- [ ] **M7A-01-03 相反数与绝对值**：相反数的意义；绝对值是数轴上的点到原点的距离；求一个数的相反数和绝对值。  
  边界：不要求含绝对值的方程或分类讨论的综合题  
  课标：S-NUM-2
- [ ] **M7A-01-04 有理数的大小比较**：利用数轴或绝对值比较有理数大小；两个负数绝对值大的反而小。  
  课标：S-NUM-1

### 第二章 有理数的运算

- [ ] **M7A-02-01 有理数的加法与减法**：有理数加法法则、减法转化为加法、加减混合运算。  
  课标：S-NUM-3、S-NUM-4
- [ ] **M7A-02-02 有理数的乘法与除法**：有理数乘除法法则、倒数、运算律。  
  课标：S-NUM-3、S-NUM-4
- [ ] **M7A-02-03 有理数的乘方与混合运算**：乘方的意义；含乘方的有理数混合运算（以三步以内为主）。  
  课标：S-NUM-3
- [ ] **M7A-02-04 科学记数法与近似数**：用科学记数法表示较大的数；近似数与精确度。

### 第三章 代数式

- [ ] **M7A-03-01 用字母表示数**：用字母表示数、运算律、公式和数量关系，体会字母表示数的一般性。  
  课标：S-ALG-1
- [ ] **M7A-03-02 代数式的概念与书写规范**：认识代数式；代数式中乘号的省略、数字因数前置、除号写成分数线等书写规范。  
  课标：S-ALG-1
- [ ] **M7A-03-03 列代数式表示数量关系**：分析实际问题中的简单数量关系，用代数式表示；理解代数式的实际意义。  
  课标：S-ALG-2
- [ ] **M7A-03-04 代数式的值**：把字母的值代入代数式计算；根据公式代入具体值计算。  
  课标：S-ALG-3
- [ ] **M7A-03-05 整体代入求值**：把一个代数式看作整体代入求值。  
  边界：不要求先因式分解再整体代入  
  课标：S-ALG-3

### 第四章 整式的加减

- [ ] **M7A-04-01 单项式及其系数和次数**：单项式的概念；系数（含符号和π）；次数是所有字母的指数和。  
  课标：S-POL-1
- [ ] **M7A-04-02 多项式的项、次数与常数项**：多项式的项和常数项；多项式的次数是次数最高的项的次数；按某个字母升幂或降幂排列。  
  课标：S-POL-1
- [ ] **M7A-04-03 整式的概念**：单项式与多项式统称整式；分母含字母的式子不是整式。  
  课标：S-POL-1
- [ ] **M7A-04-04 同类项**：同类项的判定：所含字母相同，并且相同字母的指数也相同；已知同类项求字母指数。  
  课标：S-POL-1
- [ ] **M7A-04-05 合并同类项**：把同类项的系数相加，字母和字母的指数不变。  
  课标：S-POL-1
- [ ] **M7A-04-06 去括号**：括号前是“+”号，去括号后各项不变号；括号前是“-”号，去括号后各项都改变符号。  
  课标：S-POL-1
- [ ] **M7A-04-07 整式的加减与化简求值**：整式加减的一般步骤：去括号、合并同类项；先化简再代入求值。  
  边界：只涉及整式的加减，不涉及单项式乘多项式、多项式乘多项式  
  课标：S-POL-1、S-ALG-3
- [ ] **M7A-04-08 整式加减的实际应用**：用整式表示实际问题中的量并进行加减运算，如周长、两位数、日历中的数。  
  课标：S-POL-1、S-ALG-2

### 第五章 一元一次方程

- [ ] **M7A-05-01 方程与列方程**：含有未知数的等式叫方程；找等量关系、设未知数、列方程。  
  课标：S-EQ-1
- [ ] **M7A-05-02 一元一次方程的概念**：只含一个未知数、未知数的次数都是 1、等号两边都是整式的方程。  
  课标：S-EQ-1
- [ ] **M7A-05-03 方程的解**：使方程左右两边相等的未知数的值；检验一个数是否为方程的解；已知解求方程中的字母。  
  课标：S-EQ-1
- [ ] **M7A-05-04 等式的基本性质**：等式两边加（或减）同一个数（或式子），结果仍相等；两边乘同一个数，或除以同一个不为 0 的数，结果仍相等。  
  课标：S-EQ-2
- [ ] **M7A-05-05 解方程：合并同类项与移项**：把等式一边的某项变号后移到另一边；合并同类项；系数化为 1。  
  课标：S-EQ-3
- [ ] **M7A-05-06 解方程：去括号**：先按去括号法则去括号，再移项、合并、系数化为 1。  
  课标：S-EQ-3
- [ ] **M7A-05-07 解方程：去分母**：方程两边同乘各分母的最小公倍数；不漏乘不含分母的项；分子是多项式时去分母后加括号。  
  边界：分母只能是数字；分母中含未知数的是分式方程，属八年级内容  
  课标：S-EQ-3
- [ ] **M7A-05-08 解一元一次方程的一般步骤**：根据方程特点灵活选用：去分母、去括号、移项、合并同类项、系数化为 1。  
  课标：S-EQ-3
- [ ] **M7A-05-09 含字母参数的一元一次方程**：已知解或解的特征求参数；两个方程同解求参数。  
  边界：不要求对参数进行系统的分类讨论  
  课标：S-EQ-1、S-EQ-3
- [ ] **M7A-05-10 应用：和差倍分与配套问题**：根据倍数、和差或配套比例关系列一元一次方程。  
  课标：S-EQ-1、S-EQ-5
- [ ] **M7A-05-11 应用：工程问题**：工作总量 = 工作效率 × 工作时间，常把工作总量看作 1。  
  课标：S-EQ-1、S-EQ-5
- [ ] **M7A-05-12 应用：行程问题**：路程 = 速度 × 时间；相遇时路程和等于总路程，追及时路程差等于原来的距离；顺水速度 = 静水速度 + 水速。  
  课标：S-EQ-1、S-EQ-5
- [ ] **M7A-05-13 应用：销售与利润问题**：利润 = 售价 − 进价，利润率 = 利润 ÷ 进价；打 n 折即按标价的 n/10 出售。  
  课标：S-EQ-1、S-EQ-5
- [ ] **M7A-05-14 应用：方案选择与分段计费**：列方程求两种方案费用相等的情况，再比较给定数值下哪种更省；比赛积分、分段计费。  
  边界：只比较给定数值或求相等点；求“在什么范围内更省”需要不等式，属七年级下册  
  课标：S-EQ-1、S-EQ-5
- [ ] **M7A-05-15 应用：几何图形与等积变形**：根据周长、面积或体积不变等关系列方程。  
  课标：S-EQ-1、S-EQ-5
