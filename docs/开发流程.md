# 开发流程

项目分六个阶段完成，图中双线框表示该阶段的评测。（图片版：[开发流程.png](开发流程.png)）

```mermaid
flowchart TB
    A[明确定位：教师参与审核的对话式出卷助手<br/>数学 1～7 年级、英语 3～7 年级] --> S1

    subgraph S1[一、骨架]
        direction LR
        B[领域模型<br/>需求、蓝图、题目、试卷快照] --> B2[结构化调用<br/>Pydantic 校验 + 带反馈重试] --> B3[配分求解器、不变量校验<br/>SQLite 版本快照]
    end

    subgraph S2[二、对话式修改]
        direction LR
        C[换题、改题型、增删题<br/>调分值、加约束] --> C2[只重出目标题<br/>内容指纹证明其他题不变] --> C3[撤销、版本历史与差异]
    end

    subgraph S3[三、多 Agent 审核与工具验题]
        direction LR
        D[盲解 Agent<br/>看不到答案、独立列式] --> D2[精确求解器<br/>+ 教学审核 Agent] --> D3[返修闭环与停止条件<br/>验证状态如实标注] --> D4[[审核消融实验]]
    end

    subgraph S4[四、课程知识库与混合检索]
        direction LR
        E[年级-册-单元-知识点建库<br/>人工核对目录、模型起草、代码校验] --> E2[BM25 + 向量 + RRF<br/>元数据过滤] --> E3[规划只选范围内知识点<br/>英语语法分级与阅读难度] --> E4[[检索评测]]
    end

    subgraph S5[五、交付与可用性]
        direction LR
        F[PDF 导出<br/>学生版 / 答案版] --> F2[网页<br/>FastAPI + SSE 实时进度、限流] --> F3[公开访问<br/>Cloudflare 隧道]
    end

    subgraph S6[六、修改与讨论 Agent 与整体评测]
        direction LR
        G[ReAct：只读工具 + 代码校验执行<br/>单题恢复、局部改字、讨论试卷] --> G2[[修改规划评测<br/>开发集 → 留出集]] --> G3[[端到端评测<br/>开发集 → 留出集]] --> G4[[人工抽检 60 题]]
    end

    S1 --> S2 --> S3 --> S4 --> S5 --> S6
```

每个阶段内部都按同一个循环推进：

```mermaid
flowchart LR
    I[实现] --> X[实验 / 真实使用] --> Y[逐条归因] --> Z[修复 + 回归测试] --> I
    X --> H[[最终结果用留出集报告<br/>只评测一次、不据此调参]]
```

## 各阶段的验证方式

| 阶段 | 怎么证明有效 |
|---|---|
| 骨架 | 离线测试：所有模型调用都用脚本化的假模型代替 |
| 对话式修改 | 内容指纹校验；修改场景测试 |
| 审核与工具验题 | 40 题标注集上的消融实验：答案计算错误检出率从 21%～38% 提高到 92%～96% |
| 知识库与检索 | 63 条分类查询的检索评测；用实验数据决定不启用重排 |
| 交付 | 浏览器自动化测试网页；用临时公开链接实际访问 |
| 修改与讨论、整体评测 | 留出集：修改规划正确率 67% → 100%；端到端出卷 98%、修改 97%；人工抽检 60 题 |
